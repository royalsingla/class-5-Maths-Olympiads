# Assignments

Topic-wise practice worksheets, one folder per week of the plan in
`../docs/03-practice-plan.md`. Each folder (once built) contains:

- `assignment.md` — the questions (4-option MCQ, Class 5 difficulty)
- `answer-key.md` — correct options with a short worked explanation each

## Folder list (per the 12-week plan)

| Folder | Topic | Status |
|---|---|---|
| `01-number-sense/` | Place value (7–8 digit numbers), number names, ordering, rounding, Roman numerals | ✅ Built |
| `02-four-operations/` | Addition, subtraction, multiplication, division (large numbers + word problems) | ✅ Built |
| `03-factors-multiples-patterns/` | Factors, multiples, HCF/LCM, number patterns | ✅ Built |
| `04-fractions-decimals/` | Comparing & equivalent fractions, decimal operations | ✅ Built |
| `05-percentage-ratio-profit-loss/` | Percentage, ratio & proportion, profit/loss, simple interest | ✅ Built |
| `06-measurement-money/` | Length, weight, capacity, time, temperature, money, conversions | ✅ Built |
| `07-geometry-perimeter-area/` | Shapes, symmetry, perimeter, area of rectangle/square | ✅ Built |
| `08-data-handling/` | Tally marks, pictographs, bar graphs | ✅ Built |
| `09-reasoning-patterns-coding/` | Patterns, analogy, classification, alphabet test, coding–decoding, logical sequence of words, puzzle test | ✅ Built |
| `10-reasoning-direction-figures/` | Ranking, direction sense, mirror & water images, embedded figures, clock & calendar | ✅ Built (18 Q) |
| `11-achievers-hots/` | Multi-step HOTS problems across all topics above | ✅ Built |

All 11 folders are built in the same two-file (`assignment.md` +
`answer-key.md`) shape, 15 questions each — except
`10-reasoning-direction-figures/`, which has 18 (10 text-based + 8
diagram-based). `08-data-handling/` and `10-reasoning-direction-figures/`
also ship an `images/` folder of SVG diagrams referenced from their
`assignment.md`, built the same way as the
[Class 4 kit](https://github.com/royalsingla/Class-4-Maths-Olympiads).

Class 5's Week 10 adds **water images** alongside mirror images — the
upside-down reflection you'd see below a water surface, as distinct from
a left-right mirror flip. The `images/water-q14.svg` question uses the
letters b/d/p/q, which are exactly the four ways of flipping one shape —
a genuinely useful way to see the difference.
