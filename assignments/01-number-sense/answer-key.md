# Week 1 — Number Sense & Numerals — Answer Key

**Q1. D) 7,00,000** — In the Indian place-value system, 7,25,364 has
digits 7‑2‑5‑3‑6‑4: 7 is in the **lakhs** place, so its value is
7 × 1,00,000 = 7,00,000.

**Q2. A) Eight lakh thirty-four thousand five hundred twenty-one** —
8,34,521 reads as 8 lakh, 34 thousand, 521.

**Q3. A) 50,00,000 + 6,00,000 + 90,000 + 200 + 10 + 7** — 56,90,217:
5 = ten-lakhs (50,00,000), 6 = lakhs (6,00,000), 9 = ten-thousands
(90,000), 0 = thousands (skipped), 2 = hundreds (200), 1 = tens (10),
7 = ones (7).

**Q4. D) 34,65,987** — Comparing after "34,": 56789, 65789, 56987, 65987 —
the largest is 65987.

**Q5. B) 6,75,000** — Rounding to the nearest thousand looks at the
hundreds digit (8); since 8 ≥ 5, round up: 674 thousand → 675 thousand.

**Q6. A) XCIV** — 94 = 90 (XC) + 4 (IV) = XCIV.

**Q7. B) 89** — LXXXIX = L(50) + X(10) + X(10) + X(10) + IX(9) = 89.

**Q8. B) 1,00,00,000** — 99,99,999 + 1 = 1,00,00,000 (one crore).

**Q9. A) 49,99,999** — 50,00,000 − 1 = 49,99,999.

**Q10. A) 23,54,876; 23,54,678; 23,45,876; 23,45,678** — Comparing the
last 4 digits of each (after "23,"): 54876 > 54678 > 45876 > 45678.

**Q11. B) 100** — 1 crore = 1,00,00,000; 1 lakh = 1,00,000;
1,00,00,000 ÷ 1,00,000 = 100.

**Q12. B) 1,00,000** — The pattern adds 25,000 each time: 25,000;
50,000; 75,000; 1,00,000; 1,25,000.

**Q13. B) 29** — The pattern adds 6 each time: 5, 11, 17, 23, 29.

**Q14. B) 450** — A number divisible by both 2 and 5 must be divisible
by 10, i.e. end in 0. Only 450 ends in 0.

**Q15. A) 5,30,246** — 5,00,000 + 30,000 + 0 + 200 + 40 + 6 = 5,30,246.
