# Assignments

Topic-wise practice worksheets, one folder per week of the plan in
`../docs/03-practice-plan.md`. Each folder (once built) contains:

- `assignment.md` — the questions (4-option MCQ, Class 5 difficulty)
- `answer-key.md` — correct options with a short worked explanation each

## Folder list (per the 12-week plan)

| Folder | Topic | Status |
|---|---|---|
| `01-number-sense/` | Place value (7–8 digit numbers), number names, ordering, rounding, Roman numerals | ✅ Built |
| `02-four-operations/` | Addition, subtraction, multiplication, division (large numbers + word problems) | Planned |
| `03-factors-multiples-patterns/` | Factors, multiples, HCF/LCM, number patterns | Planned |
| `04-fractions-decimals/` | Comparing & equivalent fractions, decimal operations | Planned |
| `05-percentage-ratio-profit-loss/` | Percentage, ratio & proportion, profit/loss, simple interest | Planned |
| `06-measurement-money/` | Length, weight, capacity, time, temperature, money, conversions | Planned |
| `07-geometry-perimeter-area/` | Shapes, symmetry, perimeter, area of rectangle/square | Planned |
| `08-data-handling/` | Tally marks, pictographs, bar graphs | Planned |
| `09-reasoning-patterns-coding/` | Patterns, analogy, classification, alphabet test, coding–decoding, logical sequence of words, puzzle test | Planned |
| `10-reasoning-direction-figures/` | Ranking, direction sense, mirror & water images, embedded figures, clock & calendar | Planned |
| `11-achievers-hots/` | Multi-step HOTS problems across all topics above | Planned |

"Planned" folders are specified in `docs/03-practice-plan.md` (topic +
week) and should follow the exact question-count/format of
`01-number-sense/` when built — see the
[Class 4 kit](https://github.com/royalsingla/Class-4-Maths-Olympiads) for
the fully-built reference (including how it handles diagram-based
reasoning questions with real SVG figures).
