# 12-Week Practice Plan — Class 5 Mathematics Olympiad

Built around the SOF IMO pattern (50 Q / 60 marks / 60 min — see
`02-exam-pattern.md`). Same three-phase shape as the Class 4 plan: build
core skills topic by topic, add pure logical reasoning, then stress-test
with full timed papers — with one extra core week, since Class 5 adds two
genuinely new topic areas over Class 4.

Suggested pace: **3 short sessions a week, ~30–40 minutes each**.

## Phase 1 — Core Skills (Weeks 1–8)

| Week | Topic | Folder |
|---|---|---|
| 1 | Number Sense & Numerals (7–8 digit numbers, lakhs/crores, Roman numerals, rounding) | `assignments/01-number-sense/` ✅ |
| 2 | Four Operations (large numbers, multi-digit, word problems) | `assignments/02-four-operations/` ✅ |
| 3 | Factors, Multiples, HCF/LCM & Number Patterns | `assignments/03-factors-multiples-patterns/` ✅ |
| 4 | Fractions & Decimals | `assignments/04-fractions-decimals/` ✅ |
| 5 | **Percentage, Ratio & Proportion, Profit/Loss & Simple Interest** (new vs. Class 4) | `assignments/05-percentage-ratio-profit-loss/` ✅ |
| 6 | Measurement (Length, Weight, Capacity, Time, Temperature) & Money | `assignments/06-measurement-money/` ✅ |
| 7 | Geometry, Symmetry, Perimeter & Area | `assignments/07-geometry-perimeter-area/` ✅ |
| 8 | Data Handling | `assignments/08-data-handling/` ✅ |

**Weekly routine:** attempt the assignment untimed first; mark it against
the answer key; redo only the missed questions 2 days later.

| Week | Topic | Folder |
|---|---|---|
| 9 | Patterns, Analogy & Classification, Alphabet Test, Coding–Decoding, Logical Sequence of Words, Puzzle Test | `assignments/09-reasoning-patterns-coding/` ✅ |

## Phase 3 — Achievers / HOTS + Full Paper (Weeks 11–12)

| Week | Activity |
|---|---|
| 11 | `assignments/11-achievers-hots/` ✅ — 2-and-3-step mixed problems pulling from every Phase‑1 topic. Then attempt **Sample Paper 1** (untimed, open-book) to find the gaps — see `sample-papers/README.md`. |
| 12 | Attempt **Sample Papers 2–6**, each **strictly timed to 60 minutes**, one every 1–2 days. After each paper, log every wrong answer in an error log (topic + why it was wrong) before moving to the next paper. |

## Optional extension

Once the core plan is comfortably done, the Class 4 kit's
[Math Kangaroo-style stretch set](https://github.com/royalsingla/Class-4-Maths-Olympiads/tree/main/assignments/12-math-kangaroo-stretch)
is equally suitable here — Math Kangaroo's grade bands overlap (the
"Ecolier" level spans grades 3–4, "Benjamin" spans grades 5–6), so a
Class 5 student is better matched to the *next* band up in puzzle
difficulty rather than that exact set. Worth building a Class-5-pitched
version of it as a future addition.
